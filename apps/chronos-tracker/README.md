# C.H.R.O.N.O.S. Tracker

Mobile Tracking, Geo-Intelligence, and Sovereign Map system.

## Tech Stack
- Supabase PostGIS
- MapLibre GL JS
- Next.js 14

## Features
- Mobile target tracking
- Sovereign Map rendering (offline-capable)
- Rental vehicle management (Rungroj / Jaijai)
- Geo-fencing and alert zones
