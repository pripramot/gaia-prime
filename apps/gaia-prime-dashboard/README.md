# GAIA PRIME Dashboard

Main dashboard application for the PRIAM Master Orchestrator.

## Tech Stack
- Next.js 14 (App Router)
- React
- MapLibre GL JS (for CHRONOS Geo-Intelligence)
- Supabase Client (Local)

## Features
- Agent status monitoring
- Real-time data feeds via Supabase Realtime
- Geo-Intelligence map overlay (CHRONOS integration)
- Digital Forensics case management (Phuphadang integration)
